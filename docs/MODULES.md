# Module Guide

This document describes the current `src/` modules. These modules contain only logic already validated in notebooks.

## `src/config.py`

Stores target-country configuration, GDELT-to-ISO3 mapping, and the operational baseline feature list.

Main objects:

- `JAPAN`
- `CHINA`
- `GDELT_TO_ISO3`
- `ISO3_TO_GDELT`
- `OPERATIONAL_FEATURES`

## `src/portwatch.py`

Handles IMF PortWatch country-level operational data.

Main functions:

- `fetch_country_daily(iso3)`
- `build_weekly_operational_base(daily)`
- `load_operational_base(path)`

## `src/wits.py`

Handles WITS bilateral partner trade data and import dependency weights.

Main functions:

- `fetch_partner_trade(reporter, year, indicator="MPRT-TRD-VL")`
- `build_partner_dependency_weights(trade_df, partner_iso3, normalize_within_subset=True)`

## `src/gkg_bigquery.py`

Builds and runs GDELT GKG BigQuery queries.

Main functions:

- `make_client(project)`
- `build_country_week_event_query(start_date, end_date, gdelt_codes)`
- `estimate_query_gb(client, query)`
- `run_query(client, query, maximum_gb_billed)`

All GKG queries generated by this module include `_PARTITIONDATE` filters.

## `src/network_exposure.py`

Converts partner-country event features into network-weighted exposure.

Main functions:

- `attach_iso3_codes(event_features, gdelt_to_iso3)`
- `compute_network_exposure(event_features, dependency_weights)`
- `merge_exposure_with_operational_base(operational_df, network_exposure, how="left")`
