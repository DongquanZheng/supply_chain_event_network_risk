# Public Release Checklist

This repository is prepared as a public research-code release.

## Included

- `src/`: reusable data access and feature-construction modules.
- `scripts/`: reproducible dataset, modeling, robustness, and figure scripts.
- `tests/`: fast offline tests for schema, temporal splits, leakage guardrails, and deterministic placebo features.
- `docs/`: methodology, data sources, benchmark plan, decisions, and reproducibility notes.
- `paper/`: paper outline and cautious contribution-claim variants.
- `reports/`: generated markdown summaries, aggregate result tables, and publication-style figures.

## Excluded

- Private proposal drafts and Word documents.
- Credentials, local cloud configuration, environment files, and service-account keys.
- Raw, interim, and processed data files that are large, source-restricted, or regenerated by scripts.
- Exploratory notebooks, notebook outputs, local paths, and interactive analysis history.
- Row-level prediction dumps and selected prediction diagnostics that are reproducible but not needed for a minimal public repository.

## Release Checks

Before pushing:

```bash
git status --short --ignored
python -m unittest discover -s tests
```

Confirm that ignored files include local data caches, notebooks, credentials if present, and private drafts.
